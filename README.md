# ComePuntos 🟡

Aprende **C# básico armando un videojuego**, con lecciones cortas al estilo Duolingo.

El juego ya está hecho, pero le faltan 10 piezas. Cada lección enseña un concepto de C#
(variables, `if`, métodos, `bool`, ciclos `for`, arreglos, `Random`, `&&`/`||`, `Math.Abs`,
buscar el mínimo) y al final **tú escribes en C# la pieza que falta**. El juego se
actualiza en vivo mientras escribes. Cada lección incluye además un ejercicio para
aprender a **usar bien la IA**.

## Empezar

- **Web:** abre `index.html` en Chrome o Edge (no necesita internet ni instalar nada).
- **Visual Studio:** al terminar las lecciones, toca **Copiar mi código**, ábrelo en
  `proyecto-csharp/ComePuntos.csproj`, pégalo en `Program.cs` entre
  `PEGA AQUÍ TU CÓDIGO` y `FIN DE TU CÓDIGO`, y presiona **F5**.

## Contenido

| Ruta | Qué es |
|---|---|
| `index.html` | La web completa (lecciones + juego + revisor de C#) |
| `proyecto-csharp/` | Proyecto de consola de Visual Studio (.NET 8+) donde corre tu código C# |
| `publicar/comepuntos.html` | La misma web, en el formato para publicarla en línea |
| `GUIA_PROFESOR.md` | Cómo usarla en clase, las 10 lecciones y cómo agregar más |
